NovelTea Engine

This app is a window onto a NovelTea Engine server. Enter the address of one that is running.

Start the server first (see the README): python main.py in NovelTeaApp/backend.
A server on another computer must be started with NOVELTEA_HOST=0.0.0.0, ideally behind a private network such as Tailscale.
Press Ctrl+Shift+K any time to come back to this screen.
