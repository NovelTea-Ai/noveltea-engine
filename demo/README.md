# Demo project

`the_lantern_court/` is a small, fully fictional demo project (a fantasy mystery) written for this repository: a brief, cast,
systems, lore, a conspiracy tree, timeline, foes, roster, arcs, chapter plans and one written chapter.

In the app, click **Open the demo project** on the dashboard. It copies these files into your workspace (`corpus/projects/` and
`corpus/generated/`). Nothing here comes from a real novel.
